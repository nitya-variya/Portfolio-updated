# Custom Fonts Directory

Place your custom webfont files here for local loading:

### 1. Title Font: New Spirit Condensed
Any of these filenames will be automatically loaded by `@font-face`:
- `NewSpiritCondensed.woff2`
- `NewSpiritCondensed.woff`
- `NewSpiritCondensed.otf`
- `NewSpiritCondensed.ttf`

### 2. Description Font: ABC Social
Any of these filenames will be automatically loaded by `@font-face`:
- `ABCSocial.woff2`
- `ABCSocial.woff`
- `ABCSocial.otf`
- `ABCSocial.ttf`

If the fonts are also installed locally on your system, the browser will also resolve them automatically via `local('New Spirit Condensed')` and `local('ABC Social')`.
